WHY XBOXPAD · 核心黑科技

从底层渲染到外设接管，全链路原生重构

专为 Apple Silicon 与 iPad Pro 屏幕打磨，把每一项硬件能力真正用到游戏串流上。

画质引擎 · Native Metal
吃透 iPad Pro 顶级屏幕
  • 2K 1440p 高码率本地串流 突破官方移动端 1080p 低码率限制，远景纹理与暗部层次大幅提升。
  • Apple MetalFX 硬件空间超分 原生调用 MTLFXSpatialScaler 硬件管线，低带宽与云游戏画面同样清脆。
  • 120Hz 双向光流补帧 自研金字塔双向光流 + 遮挡检测，将 60fps 串流丝滑推至 ProMotion 120Hz。
  • 原生 EDR Auto-HDR + 暗场去色带 自然 / 鲜艳 / 影院三档直驱 XDR/OLED 峰值亮度，内置机身温控保护。
操控接管 · Pro Controls
手柄、键鼠、西瓜键一步到位
  • 真·实体西瓜键（Xbox Home） 原生 GameController 接管，按西瓜键直接呼出 Xbox 菜单，告别误跳系统游戏中心。
  • 1–4P 多手柄同玩 + 型号电量识别 同时支持 4 只手柄联机，识别 Xbox / Elite 2 / PS5 DualSense / Switch Pro 型号与电量。
  • 外接鼠标键盘双模式 + 指针锁定 支持「手柄模拟（兼容 100% 游戏）」与「原生 Xbox 键鼠」双协议随时切换。
  • 扳机震动 + 陀螺仪 + 触控手柄 CoreHaptics 扳机/握把独立震动、左右摇杆死区与曲线微调、体感瞄准与虚拟手柄。
全能生态 · Full Ecosystem
客厅、通勤、开黑全场景覆盖
  • xCloud 云游戏免折腾 · 一键切区 内置日本 / 韩国 / 美国节点切换与自动回退，解决非支持区无法进入云游戏的痛点。
  • 原生 48kHz Opus 语音开麦 AudioToolbox 硬件编码直推 Xbox 语音通道，组队派对直接开麦沟通。
  • USB-C / HDMI 外接屏真 16:9 全屏 独立外接屏场景无黑边输出，自带 iPad OLED 息屏防烧屏遮罩，并支持 AirPlay。
  • 极简悬浮栏 + 无损截屏 + 30s HUD 点击画面空白立即收起控制栏；内置原画截屏存相册、实时双折线延迟监控与一键刷新帧。

GET STARTED · 快速安装

3 步开启 OTA 自动更新

推荐使用 SideStore 订阅源安装，后续每次发布新版直接一键更新，无需反复导包。

1

准备 SideStore

在你的 iPad / iPhone 上安装好 SideStore（也兼容 AltStore、TrollStore 或其他自签工具直接安装 IPA）。

2

添加 XboxPad 订阅源

在 iPad Safari 中点击页面顶部的「一键添加到 SideStore」，或在 Sources 中手动粘贴 https://xbox.lynkco.site/source.json。

3

登录 Xbox 开玩

安装完成后打开 XboxPad 登录微软账号，局域网内即可秒连 Xbox 主机，或在云游戏页一键切换日/韩/美节点畅玩 xCloud。

小贴士 · 实体手柄西瓜键 & 公网自建中继：
1. 实体西瓜键接管：连接手柄后前往 iPadOS 设置 → 通用 → 游戏手柄 → 主屏幕按钮，开启 「主屏幕按钮覆盖」，按西瓜键即可直接呼出 Xbox 主机菜单。
2. 公网穿透中继：本站 SideStore 官方订阅源版已内置多节点公网打洞/中继加速集群（开箱即用，也可手动覆盖）；GitHub 开源自行编译版不含私有中继服务器，可在 App 设置 → 区服与网络 中手动填写自建 STUN / TURN 服务器（详见 GitHub 配置指南）。
